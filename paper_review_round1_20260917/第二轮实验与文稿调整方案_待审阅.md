# 第二轮实验与文稿调整方案（待作者审阅）

## 0. 状态与原则

本文件是待审阅计划，不代表下列新实验已经执行。本次不启动训练、不删除论文内容、不改旧实验数值。作者已明确：T2-C 描述量以产生实验结果的真实实现为准，不再保留此前暂缓处理的六/八维不一致。

目标是回答三个问题：结构化稀疏闭合是否优于公平的学习动力学基线；物理空间融合是否改善整个预测窗口且其物理代价可量化；完整预测路径的成本是否合理。外部方法重相关性和可靠实现，不追求数量。

采用项目执行流程：先锁定模型/数据/评价契约，再复核已有结果，最后启动必要训练；每一阶段都有独立验收条件。

### C. 有数据时追加，不作为无条件硬任务

- H–P 原时域 2×/4× 冻结 rollout，标为超支持诊断；不重置、不注入真值、不更新 alpha。
- 有足够振荡周期时测幅值、主频、相位；短窗口/近稳态以时序和能量为主，相位可 N/A。

- local/global POD 对完整 FOM 的 projection floor，可无训练测量，用于区分表征和动力学误差。

## 4. 内部对照：少而能区分机制

### 4.1 融合对照（方柱 SH、HP，两接口）

保留两候选各自、E2 Top-1、Equal、E2 probability、mu-only、full T2-C；加入/复核：

- validation-selected fixed specialist：只用验证选一个模型，区别于 test-selected Best fixed；
- train-fit constant alpha：复用已完成结果；
- constant logit offset：每接口一个可训练偏置，alpha=sigmoid(logit(pi_pair)+beta)，检查是否只是 E2 总体校准；
- oracle 单独区域列示，明确 window mean、squared objective、terminal 中究竟优化哪一个，永不列为可部署方法。

轻量标量目标尽量采用确定性有界优化。不存在随机初始化的解析标量拟合不机械做三种子。既有 full/mu-only 三种子可在同协议下复用。

### 4.2 局部动力学核心对照（优先 Circular H、P）

| 方法 | 控制因素 | 回答的问题 |
|---|---|---|
| Proposed | 已核实真实模型，若使用原 checkpoint 则标单种子参考 | 完整模型 |
| Monolithic NN closure | 相同本地 POD、骨架、压力接口、历史与 rollout；用普通非路由网络替代闭合 | 是否普通学习闭合已经足够 |
| Structured non-routed closure | 保留 nonlinear+linear+low-rank quadratic 三支，取消条件路由 | 收益是否来自 routing，而不只是分支结构 |

默认新神经对照以单次预测 active 参数约匹配为起点（计划目标 ±5%，不可达时报告实际差异），随后实测时间；不得称作已匹配 FLOPs。每次询问激活规模与全部存储容量分列。既有 Periodic total-matched Dense 单列补充，不混入 active-matched 组。

选择 Circular H/P 是因为其模型证据较明确、已具有固定支持/变化支持的诊断。若需把机制结论推广到 Pinball 主表，必须先核实 Pinball 实际方法身份，再在对应 H/P 上追加同协议 NN closure；不拿圆柱结果冒充 Pinball 证明。

### 4.3 训练量与执行顺序

核心上限：2 regimes × 3 neural methods × 3 seeds = 18 次训练（包含 proposed 的独立重复，不是 18 个全新算法）。只有原 run 完全符合冻结协议才能抵扣。先做小型实现/梯度测试和验证侧试训，再按统一预算完成三种子；不因某个方法第一种子测试结果差而少跑后续种子。

调参预算额外独立登记，默认各神经方法相同的小网格验证预算，例如三个学习率候选；最终种子评估沿用锁定配置。总参数控制、Pinball 扩展、完整 E2+gate+specialists 重训均是额外工作，不默认为已授权的无限矩阵。

三种子默认是 specialist-level variability，不叫完整 pipeline 三种子。外部确定性回归模型不机械重复同一求解三次。

## 5. 外部方法选择

推荐“一个必做外部基线 + 一个条件性局部方法”，另保留有效的匹配神经闭合控制。

### 5.1 首选：正则化 Polynomial Operator Inference（必做建议）

原因：直接学习低维自主动力学，与 ROM 任务接近；有作者原文和维护中的实现，便于清楚控制表示、数据和初态。

首轮在 Circular H/P 上与核心模型同测。使用相同训练侧 POD/标准化、参数输入权限、初始状态、FOM 参考和物理预测时域。常数/线性/二次项及参数依赖形式在验证阶段固定，Tikhonov 强度只用验证 rollout 选择。

必须先检查 derivative targets 是否可信：若原始 RHS 可用，所有需要导数的方法使用同一训练信息；若仅有粗采样且不适合导数拟合，考虑离散时间 polynomial inference，并明确它是任务适配版本，不伪称原连续算法的完全复现。不能在近零/粗差分噪声下故意构造弱外部基线。

压力不随便遗漏：使用明确标注的共同代数压力接口进行受控动力学比较，或另拟合 train-only 压力映射并披露差异；确定前不混合 Eu+Ep 作最终排名。

这一方法不需要与神经网络采用相同 optimizer/epoch；公平性在同信息、同任务、适当且公开的验证调参预算，而非强迫异构算法使用相同优化器。

### 5.2 第二选择：ql-ROM（条件性，不立即承诺整套复现）

原因：局部 charts、intrusive local dynamics、assignment/change-of-basis，与“独立轨迹输出组装”的主张最直接相关。

先审读原文和可用代码，核查当前有无离线 intrusive operators、可用 clustering 数据与跨参数适配。若条件具备，在一个代表性局部协调任务上对比；若只实现已有 S/H/P charts 之间的硬切换，那是自定义 chart-switching control，不能命名为 ql-ROM。

聚类/POD/assignment 只用训练数据；测试不重聚类，固定物理时域及初始化，计入换基和压力处理成本。它允许在线状态切换，与窗口固定 T2-C 不同，应作为任务层面不同协调机制比较，而不是单因素 routing 消融。

### 5.3 神经闭合与其他候选的定位

- Dar–Baiges–Codina 的 ANN-corrected ROM：与流体混合 ROM 相关，可作为 monolithic NN closure 的文献依据；若未按原文完整复现，只称 adapted/matched NN closure，不伪称外部原方法复现。
- POD-DL-ROM、tLaSDI、CNM：暂不放入最低执行包。分别涉及直接参数–时间代理/初态任务适配、潜空间与热力学结构适配、统计性状态转移评价等额外问题。审读原文后若发现能够公平复现再纳入，不为了数量将不匹配的失败实现作陪衬。
- DeepONet 现有不同 cadence 的结果仍只能作辅助案例，不升级成匹配自主预测对比。

## 6. 冻结公平协议

1. 相同最终测试轨迹、初始历史、共同压力 gauge、完整 FOM 参考、物理 T/输出 cadence。
2. 内部消融使用相同 POD、骨架、压力更新、curriculum 和选模规则；移除路由后不存在的正则可删除但明确列出。
3. 每种方法允许同级别验证调参；不存在对 proposed 用完整训练、对 baseline 只用默认参数的比较。
4. 所有失败种子/窗口保留；误差只对成功样本计算时，必须同时给总完成率，不能把它当全体平均。
5. 不把已经检查过的测试结果重新称为盲测。计划先冻结，测试不参与阈值、支持集、配置和 checkpoint 选择。
6. 残差/计时缺数据时明确 not measured；不得以 trainable parameter 或后处理 proxy 替代真正 online speedup/full-order residual。

## 7. 最终呈现与阶段验收

建议正文只保留三组核心证据：局部自主预测比较、overlap 全窗口/终点比较、关键结构控制。附录保留逐 Re/seed、物理残差、时间内存、配置，不增加与正文重复的 min–max 表。

阶段顺序：

1. 文稿/身份核实：八维定义一致；Table 4 原始聚合可追溯；PPE 有真实构造出处；需测试的模型身份确认。
2. 已有模型复评：窗口曲线、常数控制、候选能量/残差、真实在线计时。
3. 新对比：Circular H/P 三种子核心组 + OpInf；ql-ROM 先过可复现性检查再决定。
4. 统一出表：raw scorecard 自动生成 LaTeX 和图；保留有利与不利结果；完整修改日志。

不预估未经测量的训练耗时。环境/单次训练试跑后给基于观测的 GPU-hours 和墙钟估计，再锁定扩展预算。
