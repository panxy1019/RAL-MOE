## 1. 勘误原因

初版评估直接使用测试集相邻快照，其时间间隔为 `Δt=0.25`；B1 训练轨迹的时间间隔中位数为 `Δt=1.0`。虽然 rollout 的 RK4 积分显式读取 `Δt`，但 B1 的 H3 历史特征、历史状态差分、有限差分导数标签和归一化统计均由训练 cadence 拟合，模型没有显式的 cadence 条件输入。

因此，原评估把约为训练幅度四分之一的历史变化量输入 H3，形成明显分布外输入。原报告中的高 Re 大误差主要是评估协议错误，不代表模型没有学到高 Re 动力学。

本次评估不修改模型、不更新超参数、不重新选择检查点，只修正时间采样协议。

## 2. 修正后的评估协议

### 2.1 Cadence 对齐

对每个 `Δt=0.25` 测试序列，按照快照下标模4拆成四条交错子序列：

```text
offset 0: frame 0, 4, 8, ...
offset 1: frame 1, 5, 9, ...
offset 2: frame 2, 6, 10, ...
offset 3: frame 3, 7, 11, ...
```

每条子序列的时间间隔均为 `Δt=1.0`，与 B1 训练 cadence 一致。四条子序列互不连接，H3 历史和 rollout next-index 不跨 offset 链传播。

### 2.2 测试集覆盖

| 测试区域 | Reynolds 数 | 原始帧数/Re | 对齐后长度/offset | 评估 horizon |
|---|---|---:|---:|---|
| HP overlap | 22.25、24.0 | 144 | 36 | K1–K32 |
| Periodic core | 27.5、31.0、34.5、38.0、43.0、50.0、57.0 | 256 | 64 | K1–K32、K56 |

- K1–K32：覆盖全部9个 final-test Re。
- K56：仅覆盖轨迹长度合法的7个 periodic-core final-test Re。
- 每个 Re/horizon 最多64个窗口。
- K56 每个 periodic-core Re 有20个合法窗口，即4个 offset 各5个窗口。
- 所有评估使用相同冻结检查点，没有真值回灌。

### 2.3 指标定义

- `U error`：速度 POD 重构场相对误差。
- `p error`：压力 POD 重构场相对误差。
- `joint error = U error + p error`。
- `terminal`：窗口最后一步的平均联合误差。
- `worst window`：对应评估集合中的最大联合误差。

误差参照为 POD 子空间重构真值，不是相对原始 CFD 全场的总误差。

## 7. 结论

1. B1 在与训练一致的 `Δt=1.0` 时间契约下，对未见 final-test Reynolds 数具有良好泛化能力。
2. 全测试集 K32 联合误差为0.841%，periodic-core K56 联合误差为1.672%。
3. 全部测试窗口有限且无发散，未观察到原报告所称的高 Re 系统性失效。
4. 压力误差仍高于速度误差，是后续模型改进和 MoE/KDA 比较的主要关注项。
5. B1 当前应被理解为 `Δt≈1.0` cadence 模型。若部署目标是原生 `Δt=0.25`，应使用 cadence 条件、对历史差分按时间归一化，或用多时间步数据重新训练；不能直接引用本报告的 `Δt=1.0` 指标代表原生四倍频率推理性能。
