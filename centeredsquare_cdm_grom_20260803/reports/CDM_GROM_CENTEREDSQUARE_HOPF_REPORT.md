# 方柱 Hopf 数据集 CDM-GROM 实施与严格审计报告

## 1. 结论

本次完成了一套与神经网络、MoE、注意力和相位输入完全独立的
Continuous Delta-Memory Galerkin ROM（CDM-GROM）实现。最终模型使用
11 个 resolved 速度模态和 53 个 unresolved 连续记忆状态，压力由 64 阶
Pressure-Poisson 代数映射恢复。

数值实施是稳定且可复现的：6 个 validation 和 5 个 frozen heldout 案例
均从 `t=8` 自主滚动到 `t=500`，没有发散；RK4 内步长从 0.1 加粗到 0.2
时，resolved 轨迹相对差异不超过 `3.81e-6`。

但预测精度不能判定为成功。CDM 相比常规 r11 GROM 在所有 11 个非训练
Re 上都有一致改善，heldout 平均速度系数误差下降 22.18%，但最终相对
误差仍为 25.05，远大于 1。该版本证明了连续记忆闭合的稳定收益，却也
表明当前纯物理 Galerkin/Pressure-Poisson 算子与 CFD 投影动力学之间存在
很强的结构误差。

报告中的 `PASS` 仅表示构建、隔离和积分检查通过，不表示预测精度达标。

## 4. 连续记忆方程

先将 Pressure-Poisson 代数压力消入速度 Galerkin 方程：

\[
\dot a = c + Aa + H(a,a)
+P\{\tilde c+\tilde A a+\tilde H(a,a)\}=F(a;Re).
\]

令 `a=(x,z)`，其中 `x∈R^11`、`z∈R^53`。每个训练参数节点以该案例最后
32 个快照的系数均值 `a*=(x*,z*)` 为参考，定义 `y=z-z*`。最终闭合为

\[
\dot x = F_r(x,z^*)+B y,
\]

\[
\dot y = f_u^*+C(x-x^*)+D_s y,
\]

其中

\[
B=\partial_zF_r(a^*),\quad
C=\partial_xF_u(a^*),\quad
D=\partial_zF_u(a^*),\quad
f_u^*=F_u(a^*).
\]

若 `α(D)>-δ`，显式采用

\[
D_s=D-[\alpha(D)+\delta]I,\qquad \delta=0.02.
\]

消去 `y` 后得到真正的连续时间矩阵记忆：

\[
y(t)=e^{D_s(t-t_0)}y(t_0)+
\int_{t_0}^{t}e^{D_s(t-s)}
\{f_u^*+C[x(s)-x^*]\}\,ds.
\]

因此该模型不是固定历史窗口，也不是离散 token 递推；记忆核由
`exp(D_s τ)` 给出。实现保留 `F_r(x,z*)` 对 `x` 的完整二次项，但忽略
`(x-x*)y` 和 `yy` 等更高阶联合扰动项。

压力输出为

\[
b(t)=\tilde c+\tilde A a(t)+\tilde H(a(t),a(t)).
\]

参数方向对所有数组做分段线性插值；区间外使用相邻末端两节点线性外推。

## 5. 参考态修正记录

首版曾采用“求得精确算子平衡点则优先使用”的规则。23 个节点虽然都将
残差收敛到 `2.75e-13` 以下，但所得平衡点范数约为 2.57，而 validation
真值系数范数仅约 0.03--0.25。滚动轨迹被吸引到该远端非物理解。

这不是求解器误差，而是参考态选择错误。连续线性化允许在非平衡参考态
展开，只要保留 `f_u*`。因此最终版本改为 train-tail 均值并显式保留仿射
残差。修正只使用了 validation 诊断；随后立即冻结，未接触 heldout。

在 train-tail 参考态处，所有节点的原始 `D` 都有 2 个不稳定特征值，谱
横坐标最大为 0.05240，因此 23 个节点均施加了 0.05918--0.07240 的显式
均匀谱移位。插值后只需数值量级的附加修正；heldout 最大附加位移为
`1.89e-5`（Re=102 外推）。这意味着最终方法应准确称为“谱正则化的
CDM-GROM”，不能称作未经修改的精确 Galerkin 消元。

## 6. 评估协议

- 前 2 个真实 resolved 间隔用于初始化记忆，即 `t=0--8`。
- 从 `t=8` 开始自主滚动，指标统计区间为 `t=12--500`。
- 主积分器：RK4，内部最大步长 0.1。
- 一致性检查：内部最大步长 0.2。
- 基线：同一 train-only POD/物理张量的常规 r11 截断 GROM，unresolved
  系数置零。
- 误差：POD 系数上的相对 L2；由于基在体积加权内积下正交，它等价于
  对应投影场能量范数上的相对误差。

这是带两个观测间隔 warm-up 的条件预测，不等同于从 `t=0` 完全盲启动。

## 9. 为什么仍不能认为模型有效

1. **POD 不是瓶颈。** 非训练案例的 64 阶速度投影残差约
   `3.1e-5--2.83e-4`，压力约 `4.6e-5--3.96e-4`，远小于 rollout 误差。
2. **物理 RHS 与 CFD 投影导数不一致。** validation 中，中心差分导数与
   完整 64 阶 RHS 的平均相对残差为 3.154。使用正号压力项优于负号
   （3.406）和无压力（3.196），支持当前符号，但三者都很差。
3. **Pressure-Poisson 输出闭合很差。** validation 上代数压力系数相对误差
   约 3.73--4.50，解释了压力 rollout 仅有约 6.7% 改善。
4. **局部一阶记忆不足。** 该模型省略的交叉/二次 unresolved 项可能在
   Hopf 增长与饱和阶段不可忽略。
5. **低 Re 真值扰动很小。** 相对于 train-only 全局均值，低 Re 的真实
   系数能量很小，使相对指标进一步放大；但预测振幅本身也明显偏大，
   所以不能仅归因于分母小。

## 10. 最终判定与后续路线

- 构建正确性：通过。
- 数据隔离与冻结：通过。
- 长时数值稳定性：通过。
- 相对 r11 基线的一致改善：通过。
- 绝对预测精度：不通过。

若继续坚持纯理论、无神经网络路线，优先级应是：

1. 改进物理 ROM 本体（边界项、压力 Poisson 边界条件和离散一致性），先把
   CFD 投影导数残差从 O(1) 降下来；
2. 在不使用 heldout 的新开发分支中加入二阶/双线性记忆项，显式保留
   `(x-x*)y`，并重新建立 validation/冻结流程；
3. 单独评估相位对齐、幅值和频率，避免单一长时点对点 L2 把相位漂移与
   幅值错误混为一谈；
4. 对 Re<Hopf 临界值和 Re>临界值分别选择物理参考支，而不是仅做参数线性
   插值。

当前 frozen heldout 不应再用于上述方法选择；下一轮改动需要新的开发验证
协议或额外保留集。
