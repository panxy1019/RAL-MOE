# RAL-MoE-ROM ICLR 2027 conversion

This directory is an independent, anonymous ICLR 2027 manuscript derived from the downloaded journal project. The journal source is not modified.

## Build entry point

- `main.tex`
- bibliography: `references.bib` and `legacy_references.bib`
- official style: `iclr2027_conference.sty` and `iclr2027_conference.bst`

Compile with a standard PDFLaTeX/BibTeX sequence or upload `build/overleaf_upload.zip` to Overleaf.
The verified local build is `build/pdf/main.pdf` (12 pages total; seven-page main text, followed by references and appendices).

## Directory policy

- `sections/`: concise ICLR main text
- `appendix/`: derivations, implementation details, and full numerical tables
- `figures/`: submission figures and the deterministic compact-figure script
- `source_snapshot/`: author-side audit copy only; **do not upload this directory with the anonymous submission**
- `build/`: upload and compilation artifacts

The compact centered-square figure is generated by `scripts/build_compact_figure.ps1`. It crops the velocity columns from the original velocity--pressure rasters and draws them at native resolution; it does not synthesize or modify experimental fields.
