# 方柱 periodic FVM–GROM 上的 CDM 记忆闭合验证报告

日期：2026-08-03

## 结论

本轮严格保持已冻结的 periodic r28/r24 OpenFOAM 离散 FVM–POD–Galerkin
基线不变，只在其右端增加非神经、连续物理时间的固定地址 Delta-memory
残差闭合。结果不支持当前 CDM 结构：validation 上长期逐点误差最小的候选
具有 **0 个记忆状态**，即退化为普通代数残差校准；最好的真正记忆候选
虽然略微降低长期逐点 L2，却严重破坏极限环振幅和主频。因此方法未冻结，
held-out 未读取。

## 模型

基础动力学保持为

\[
\dot a=F_{\mathrm{FVM}}(a;\nu)+r(a,z;\nu),
\]

其中 `F_FVM` 是已冻结的 r28 速度 Galerkin 张量和 r24 线性压力闭合。
对每个记忆时间尺度引入 28 维固定地址最小状态

\[
\dot z_j=\lambda_j(\hat a-z_j),
\]

闭合为当前状态/参数特征和历史差分 `z_j-ahat` 的线性读出。这是理论文稿
中固定地址矩阵 Delta-memory 的最小有限状态实现；消去 `z_j` 后得到指数
卷积核，而不是固定快照窗口。

训练目标只使用 periodic train：

\[
q_n=\frac{a_{n+1}^{\mathrm{CFD}}-
\Phi_{\Delta t}^{\mathrm{FVM}}(a_n)}{\Delta t},
\]

即冻结物理基线一步映射的缺陷。共使用按时间稀疏抽取的 837 个训练转移。
候选包含 0、28、56 和 84 个记忆状态；validation 用 6 个既定 Re，所有
候选均滚动到 `t=500`。held-out 在整个拟合和选择阶段均未加载。

## 关键结果

原冻结 FVM–GROM validation 指标：

- 长期速度逐点相对 L2：1.1403；
- 平均极限环振幅误差：0.2134；
- 平均主频误差：0.0587；
- 平均单步速度误差：0.0599。

按预注册“稳定且长期速度 L2 最小”选出的候选是零记忆代数校准：

- rates：空；ridge=1；记忆维数=0；
- 长期速度 L2：1.0704；
- 振幅误差：0.4448；
- 主频误差：0.2439；
- 单步误差：0.0948。

它虽然使长期逐点误差下降约 6.1%，却让振幅误差约增至 2.08 倍、主频误差
约增至 4.16 倍、单步误差增至约 1.58 倍，因此不能视为更好的动力系统。

最好的真正 CDM 候选为 `rates=[0.01,0.05]`、ridge=10、56 个记忆状态：

- 长期速度 L2：1.0861，相对基线改善约 4.75%；
- 平均振幅误差：0.4074，相对基线恶化约 90.9%；
- 平均主频误差：0.2764，相对基线恶化约 371%；
- 所有 validation 工况数值稳定。

按“稳定、长期 L2 改善、振幅和频率均不得恶化超过 10%”的物理门槛，
没有任何真正记忆候选通过。

## 严格分析

1. 本轮不能把长期逐点 L2 的小幅下降解释成记忆成功。周期轨道的相位、
   振幅和主频必须同时检查；当前闭合通过改变频率来偶然减小部分时间段的
   点对点误差。
2. 一步缺陷除截断记忆外，还包含张量化 `linearUpwind` 误差、线性压力闭合
   误差和有限快照间隔下的流映射误差。简单线性读出无法把这些成分分离。
3. 固定实指数核只能表达衰减历史，对振荡相位记忆效率低。periodic 方柱更
   可能需要带共轭复极点的旋转记忆块，而不是继续增加实衰减通道。
4. 选择目标只用长期 L2 不充分；这是本轮审计发现的方法学问题。后续若开
   新分支，应在运行前把振幅、频率和单步误差写入联合门槛。

## 判定与后续

- 冻结 periodic FVM–GROM：继续作为正式基线；
- 当前固定地址实指数 CDM：validation 拒绝；
- 冻结 CDM：否；
- held-out：不运行；
- 推荐下一理论分支：二维旋转记忆块
  `zdot=(sigma I + omega J)z + C phi(a)`，先由 train 残差谱确定 `omega`，再
  仅用 validation 检查振幅/频率/单步联合门槛。
