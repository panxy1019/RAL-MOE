\title{Continuous Delta-Memory Galerkin Reduced-Order Models\\
       A Deterministic Finite-State Closure Theory}
\author{Independent theory manuscript}
\date{\today}

\begin{document}
\maketitle

\begin{abstract}
Galerkin truncation generally makes the dynamics of retained modal
coefficients non-Markovian. We introduce the Continuous Delta-Memory Galerkin
Reduced-Order Model (CDM-GROM), a deterministic closure that contains no
neural network, attention mechanism, learned router, external phase, or
explicit delay-window concatenation. A channel-wise delta recurrence is
scaled by the physical time step and shown to be a first-order discretization
of a matrix memory ordinary differential equation. The resulting augmented
velocity--memory system is Markovian, whereas elimination of the memory state
produces a history-dependent equation for the resolved variables. We connect
fixed-address delta memory to minimal auxiliary states, finite exponential
Volterra kernels, and exact elimination of a linear resolved--unresolved
Galerkin splitting. We establish local well-posedness, an explicit bound for
the memory subsystem, a reciprocal energy-stable subclass, and an explicit
finite-time error bound for memory-kernel approximation. Pressure remains an
algebraic Pressure--Poisson variable. The linear correspondence is not
claimed to be exact for nonlinear Navier--Stokes dynamics, and bounded memory
alone is not claimed to imply global stability of the coupled ROM.
\end{abstract}
