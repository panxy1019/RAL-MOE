# E2 与 T2-C 跨案例统计补齐报告

日期：2026-09-21  
性质：只读统计与证据审计；未重训、未生成新 held-out 结果、未修改论文或检查点。

## 1. 核心结论

1. 三个案例的 E2 都是独立训练的 `1 -> 24 -> 3` 参数网络，但数据单位不同：Circular 用每条完整 Re 轨迹派生的 32 个窗口行；Square 和 Pinball 用每个 chart 内唯一 Re 各一行。它们不能只用一个模糊的样本数 `N` 比较。
2. E2 的监督标签都是 chart ownership，顺序为 `S/H/P = 0/1/2`，不是候选场误差排序、稳定性概率或动态适用性标签。
3. Circular 的冻结 test 是全三类静态 Top-1 分类。其 11 条 test 轨迹全部分类正确，但最小三类 Top-1 margin 仅 `0.00459456`；该结果不构成 Circular T2-C 或真实时间跨流态转变证据。
4. Square 正式 T2-C 为预定 `(S,H)` 与 `(P,H)` 候选对、每个 held-out Re 8 个窗口、`K=24`，候选、E2 与 gate 均冻结。三种子只重复 gate 训练，不是全流程多种子。
5. **对旧审计结论作出更正：Pinball 不再是 development-only。** 已找到冻结选择后才解封的 formal final-test 全滚动结果，结果 seal 同时绑定 E2、三个候选 specialist、两个 T2-C gate 和结果文件哈希；当前论文 Appendix 的 Pinball overlap 行与该记录数值一致。
6. Square 和 Pinball 的候选支持都是实验协议预先指定的相邻对，不是网络自动生成的动态 applicability mask。Square 的 preflight 需要参考真值，Pinball formal full rollout 也没有验证任意新输入上的 OOD/弃权能力。

## 2. 统计口径

- **标签行**：实际送入 E2 分类训练/验证的行。
- **唯一 Re**：忽略 chart 标签后的 Reynolds number 去重数。
- **唯一轨迹**：一条固定几何、Re 和初始条件下的完整物理序列。现有三案例 E2 资产中未发现同一 chart、同一 split、同一 Re 对应多个初始条件；Circular 每个 Re 即一条轨迹，Square/Pinball 的 audit 也将 chart-Re 行记作 trajectory。
- **窗口**：从完整轨迹抽取的历史/预测片段。Circular E2 的分类行是窗口；Square/Pinball E2 不是窗口训练。
- **T2-C 开发缓存**：用于 gate 训练和验证的冻结候选输出。
- **formal final-test**：gate 与候选身份冻结后解封的测试结果；不得与开发验证混合。

### 6.1 Gate 的实际计算

对有序候选对 `(r,s)`：

1. 用 E2 三类 softmax 概率保留 `r,s`，再精确二项归一化；
2. 将第一候选概率裁剪到 `[1e-6,1-1e-6]` 后取 logit；
3. gate 对 9 维标准化输入给出 correction；
4. `alpha = sigmoid(logit(pi_r/(pi_r+pi_s)) + correction)`；
5. `alpha` 对一个窗口固定，速度和压力共用，融合不反馈到两个候选 rollout。

Square SH 的第一候选是 S，HP 的第一候选是 P；Pinball 同样采用 `(S,H)` 与 `(P,H)`。不能把 HP 写成 `(H,P)` 后仍沿用 alpha 的原含义。

| 控制 | 可训练/拟合自由度 | 信息 | Split 与选模 | 状态 |

## 10. 必须保留的结论边界

- E2 概率是 chart-assigned preference，不是可靠性或适用性概率。
- Square/Pinball 候选对由协议给定；没有实现一般的 `m_j(H,mu,K)` 自动检测器。
- Circular Top-1、Square terminal K24、Square full-window、Pinball full-window是不同评价对象。
- 三种子 Square 只度量 gate-training variability。
- reference、单位和聚合必须跟随各正式结果文件；不能把比例与百分数混用。
- Pinball formal final-test 已闭环，旧文档中的 development-only 判断应视为被新证据取代。
