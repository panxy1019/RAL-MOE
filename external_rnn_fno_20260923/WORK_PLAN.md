# POD–LSTM/GRU 与 FNO：执行与验收

范围：Circular H/P，两种独立循环基线，固定三帧历史与42/32个既有测试窗口；FNO先过几何门槛。绝不覆盖旧实验/论文。

1. 数据协议：训练专属父POD、现有系数标准化量、轨迹split与窗口索引/hash。训练进程读取分离的development NPZ，不加载sealed_test NPZ。
2. 数学/代码检查：零增量恒等映射、闭环有限梯度、未来真值扰动不改变预测；旧checkpoint实际复跑；旧误差复算；FNO低频傅里叶恒等测试和solid mask。
3. 固定搜索预算：每流态/每cell相同12个候选×800步；种子1248。候选是预定义预算子集，不是144组完全笛卡尔积。每流态分别选LSTM和GRU，保留二者结果。
4. 正式运行：固定配置后从头训练1248/1600/2026，各4000步；curriculum 1/4/8/16，纯闭环，无teacher forcing；每200步K48验证，最差Re联合误差优先。不因测试表现追加预算或换种子。
5. FNO：四个固定网格192×128、384×256、768×512、1536×1024；验证轨迹各17帧，20%既有完整三种子最佳模型误差阈值，双向映射与hash留存。失败则按方案停止该流态标准FNO，不生成训练/测试数值。
6. 测试与成本：所有配置冻结后一次测试；K24取K48前缀，均值/样本SD分层聚合；正式训练和CPU插值审计结束后串行计时，3预热/10重复，含物理编码解码和传输。
7. 交付：完整训练轨迹、checkpoint、窗口预测、逐步误差、逐Re/逐种子聚合、计时、源码、原始场恢复证据、FNO可行性结果及Markdown/LaTeX。明确筛选预算和停止条件，不声称官方完整复现。
